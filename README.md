# VagaTools 多语言审核整改版

包含简体中文、英语、日语、韩语、西班牙语和法语的完整页面。导航中的语言菜单允许手动切换，并在浏览器本地记住选择。首次访问没有手动选择时，页面请求同站点 `/geo` 端点，使用 Cloudflare 提供的 IP 国家代码选择语言；没有该端点时按浏览器语言选择。未覆盖的国家默认使用浏览器支持语言，否则使用英语。

## 发布

静态页面均在本目录；部署到 `www.vagatools.com` 根路径。若使用 Cloudflare Workers Assets，`worker.js` 和 `wrangler.jsonc` 提供 `/geo` 端点。若使用其他平台，请实现同源 `/geo`，返回 `{ "country": "JP" }` 这样的 JSON；没有端点仍可手动切换并按浏览器语言自动选择。不要使用跨站 IP 定位服务。
